## 额外完善

- Stage A 缓存键包含模型、提示词版本和实际提示词；缓存命中仍重新校验引文。完全无有效事实的返回不缓存。
- PDF 下载限制为 25 MiB；解析放入可终止子进程，默认 30 秒；限制页面和输出文本；全文文本缓存使用原子写入。
- 单次运行记录来源状态、范围、选择数、精读数、耗时、模型请求数和服务返回的 token。未返回 usage 时不能据此估算真实费用。
- 模型调用设置超时和有限 SDK 重试；隔离 DeepSeek 专用 thinking 参数；无效 JSON 可重试。
- 本机反馈 GET 只展示确认页，POST 验证一次性令牌；重放令牌无效；未签名本机服务拒绝非本机 Host。非本机监听必须配置签名密钥。
- `google_feedback.gs` 提供私有 Sheet 的签名确认与独立凭据 CSV；10 项离线 JavaScript 检查包括 Python 签名互操作，尚未部署 Google 服务。
- URL 渲染只允许 HTTP/HTTPS；日志不打印带签名的反馈请求路径。
- 默认不把 Zotero 标题/标签发送给模型，`ZOTERO_SHARE_WITH_MODEL=true` 才启用。Zotero 本地匹配不受影响。
- 包内二手 RSS 与 Indico 来源接入来源装配；显式 disabled 保持关闭；普通日程网页仍手工维护，不伪装成解析器。
- generic 兜底进入真实分析链；标题词只在主分类优先规则内辅助分派；期刊无分类时可根据关键词和 hint 选择。
- 新增 PR/push 离线门禁、`pip check`、短期诊断附件；自检只读仓库权限，发信任务单独具备写权限。

## 存储与迁移

### 状态 v2

`seen`：只代表确认投递的条目；arXiv ID 去除 vN。当前不单独推送旧论文修订版。

`observations`：论文 canonical ID → 实际发表日/主分类，用于去重后的采集统计。

`materials`：近七天公开论文/资讯材料，受数量与文本长度限制，供脉搏复用。

`feedback.history`：反馈需要的公开论文元数据；**不写个人 votes**，因为 Actions 可能把 state 提交到公开 fork。

读取 v1 保留 seen/fetched；旧 daily 数字来源不可信，明确清空并从新采集重建。不能恢复旧版已经错误消费的资讯，也不能把旧的随机 RSS hash 可靠迁移成 GUID；升级后资讯可能重复出现一次。原始 state 在本次操作中未修改，迁移发生在下一次运行并确认提交时。

### 反馈

`config/feedback.json` 被忽略，不随默认 workflow 提交。每维有独立时间戳；CSV 第四列应记录实际点击时间。没有时间戳的旧行按行序合并，但不覆盖有较新时间戳的本地决定。

云端每轮可从 Sheet 重取票值；state 保留历史论文元数据，所以首次重取也能学习。不能把“云端回写 state”误认为“个人票值已提交到 Git”。

反馈先前的 GET 写入端点需要更新。旧 Apps Script 继续写 GET 仍有风险，按新的 FEEDBACK 文档升级。

### 快照 v3

顶层 `items` 为完整 Paper 列表，`analysis` 包含 facts、source_text、source_sha256、source_scope。回放读取器兼容旧 `papers` / `summary_zh`，不把旧样张当作通过新证据校验的结果。

`run_pipeline(..., persist_state=True)` 现在明确报错。调用者必须在确认发送后调用 `commit_delivery`；预览不调用它。

## 保留的限制与后续验收

1. SMTP 已接受邮件、进程尚未保存状态时崩溃，仍可能重发。SMTP 与本地文件不能构成原子事务；没有声称 exactly-once。
2. 引文子串和数字回查不证明语义、单位、统计解释正确；数字转换规则是保守检查，不是科学公式引擎。
3. PDF 子进程能限制解析时间，但未设置跨平台进程内存硬上限；下载、页数和文本限制不能保证恶意文档绝对安全。
4. arXiv/Crossref 结果仍受页数、条数、元数据完整度限制；采集量不是全量投稿统计。
5. 周材料最多保存 1000 条，模型输入最多 PULSE_MAX_MATERIALS 条，不能声称覆盖所有领域动态。
6. Zotero 库内判断仅针对取到的条目，受 ZOTERO_LIMIT 和分页上限限制。
7. 外部协议、真实模型输出质量、邮件客户端显示、云端权限及签名 Apps Script 部署仍待实际验收。
8. 未运行 mypy/ruff；未做完整漏洞/许可证/历史秘密扫描。Actions 仍使用版本标签，尚未固定提交 SHA。
9. 非个人、多用户同实例和共享网络文件系统不属于本轮实现范围。

建议下一轮先以少量真实论文、HTML 输出和人工核对验证模型内容，再单独验证实际 SMTP 与 Actions。不要用一次自检通过替代这些外部验收。
